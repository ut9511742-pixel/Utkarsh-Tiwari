# Medicine Table Maker

A simple static website to create and manage a medicine schedule table.

## Features
- Add medicines with dosage, frequency, time, start date, and notes.
- Edit and delete individual rows.
- Search/filter medicines instantly.
- Export the medicine table to CSV.
- Data persistence with browser `localStorage`.

## Run locally (Node.js server)
```bash
npm start
```

Then open `http://127.0.0.1:8000`.

### Custom host/port
```bash
HOST=0.0.0.0 PORT=3000 npm start
```
